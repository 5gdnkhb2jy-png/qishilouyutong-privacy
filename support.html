骑士楼宇通 支持与联系

适用版本：iOS 1.0 及以上

本页提供「骑士楼宇通」的使用支持与联系方式。隐私相关的完整说明见《骑士楼宇通 隐私政策》。

联系我们

客服邮箱：【待填写：客服邮箱】（上线前替换为真实邮箱）。

你也可以在 App 内通过「我的 → 关于与帮助 → 联系客服」或「我的 → 关于与帮助 → 反馈」提交问题。

我们会在收到你的请求后尽快回复。

反馈时建议附带

  • 设备型号与 iOS 版本；
  • App 版本号（「我的 → 关于与帮助」内可查看）；
  • 出现问题的页面与操作步骤；
  • 如方便，附上截图或录屏。

数据与权限

  • 本 App 的楼宇、轨迹、照片与语音数据保存在你的设备上，我们无法远程读取或删除你设备上的数据。
  • 删除单条内容：在 App 内对应页面删除；删除全部本机数据：卸载 App。
  • 关闭权限：在 iOS「设置 → 隐私与安全性」中关闭定位、相机、麦克风、语音识别、Face ID 等权限。
  • 导出数据：在「我的 → 记录与数据」中导出 JSON 备份或 GPX 轨迹。
